# HomoLand.github.io

Static landing page source for [HomoLand](https://github.com/HomoLand).

- Production domain: https://homo.land
- GitHub Pages fallback: https://homoland.github.io
- Source: root of `main`

The page intentionally uses plain HTML/CSS/vanilla JS (`index.html`, `styles.css`, `app.js`) so it does not need a frontend build step.
